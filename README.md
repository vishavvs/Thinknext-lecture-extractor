# ThinkNEXT Lecture Extractor

![Python](https://img.shields.io/badge/Python-3.x-blue)
![Playwright](https://img.shields.io/badge/Playwright-Automation-green)
![Status](https://img.shields.io/badge/Status-Completed-success)

Automated lecture metadata extraction from the ThinkNEXT eLearn platform using **Python and Playwright**, with network response interception for extracting dynamically loaded lecture data.

---

## 📌 Problem

During my internship, I needed to prepare lecture date and timing information for internship documentation.

The required lecture metadata was available inside the authenticated e-learning application, but collecting it manually required repeatedly opening lectures and recording their details.

The required information included:

- Lecture title
- Lecture start date/time
- Lecture duration
- Timestamp information for IST conversion

Because the application loads lecture information dynamically, simply reading the visible HTML was not sufficient.

---

## 💡 Solution

I built a **Playwright-based Python automation** that navigates the authenticated eLearn application and extracts lecture metadata directly from the application's network responses.

Instead of depending entirely on visible page content, the automation monitors **XHR/Fetch responses**, identifies JSON payloads containing lecture information, recursively searches the returned data, and exports the extracted metadata into CSV format.

### Key Capabilities

- 🔐 **Persistent Authentication**  
  Reuses Playwright's `storage_state` to maintain an authenticated browser session without performing the login process every time.

- 📡 **Network Response Interception**  
  Monitors XHR/Fetch responses generated by the application to inspect dynamically loaded lecture data.

- 🔍 **Recursive JSON Extraction**  
  Searches nested JSON structures for the required lecture fields:
  - `title`
  - `startAtIsoString`
  - `durationInSecs`

- 🔗 **Lecture Discovery & Deduplication**  
  Discovers lecture URLs from the course page and uses sets to prevent duplicate processing.

- 🛡️ **Fault Tolerance**  
  Handles individual lecture-processing failures without terminating the entire extraction process.

- 🖥️ **Dynamic UI Handling**  
  Handles course navigation and UI elements such as rating popups encountered during lecture processing.

- 📄 **CSV Export**  
  Converts the extracted lecture metadata into a structured CSV dataset.

## 🔎 Technical Approach

The application loads lecture information dynamically through background network requests.

The automation uses Playwright's response listener to monitor relevant **XHR/Fetch responses**. When a JSON response is received, the script recursively searches nested objects for the required lecture fields.

The primary fields extracted are:

```text
title
startAtIsoString
durationInSecs
```

The timestamps returned by the application are handled in ISO/UTC format and can subsequently be converted to **IST (Indian Standard Time)** for documentation.

This approach makes the extraction less dependent on the visual structure of the application and focuses on the structured data returned by the application itself.

## 🚀 Getting Started

### Prerequisites

- Python 3.x
- Playwright
- An authenticated ThinkNEXT eLearn account

### Installation

Clone the repository:

```bash
git clone https://github.com/vishavvs/Thinknext-lecture-extractor.git
cd Thinknext-lecture-extractor
```

Install the required dependency:

```bash
pip install playwright
```

Install Playwright browsers:

```bash
playwright install
```

### Authentication Setup

The application requires an authenticated session.

The project uses Playwright's `storage_state` mechanism. Create your authenticated session and save it as:

```text
login.json
```

Place the file in the project directory before running the extractor.

### Run

```bash
python main.py
```

The extracted lecture metadata will be written to:

```text
lectures.csv
```

## 📊 Output

The generated CSV contains structured lecture information such as:

|   Field            | Description |
----------------------------------------
| `Lecture Title`    | Name of the lecture |
| `Start Date (ISO)` | Lecture start timestamp |
| `Duration (Secs)`  | Lecture duration in seconds |

The extracted timestamps can be converted from UTC/ISO format to IST when required for documentation.

## 🔐 Security

Authentication state and generated lecture data may contain user-specific information and are intentionally excluded from the repository.

The following files should **not** be committed:

```text
login.json
lectures.csv
```

Recommended `.gitignore` entries:

```gitignore
login.json
lectures.csv
```
